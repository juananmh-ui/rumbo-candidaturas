# Instrucciones de desarrollo asistido

Equipo: **Oscar Ramírez Toro y Juan Antonio Moreno Hevilla**.

- Entrega actual: v1.0 del ejercicio integrador de Acceso a Datos y Desarrollo de Interfaces.
- Java 24 o superior, Maven, persistencia exclusivamente en texto UTF-8 separado por punto y coma.
- CLI por argumentos: cada operación se ejecuta y termina. No usar Scanner, menús, JDBC, Hibernate ni JavaFX en esta entrega funcional.
- Separar consola, validación, modelo, servicio y persistencia. Documentar API pública con Javadoc.
- Las importaciones deben validar todos los registros antes de escribir. No sobrescribir datos tras un error de validación.
- Incluir pruebas JUnit 5 y Mockito para las reglas de negocio y pruebas reales de archivos y CLI.
- El diseño se crea en Figma con capas editables, componentes reutilizables y conexiones navegables.
- Los PDF y el vídeo deben identificar al equipo. La entrega se adjunta en archivos individuales, sin ZIP ni enlaces a carpetas.
- No inventar contribuciones, commits, participación en el vídeo ni pruebas que no se hayan realizado.
- Registrar decisiones, prompts y estado real en planning.md, tasks.md y docs/uso-ia.md.
